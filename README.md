# asigato

Website redesign concept for [asigatoflowers.com](https://asigatoflowers.com) — "a floral state of mind".

## What's here

- `index.html` — a self-contained, responsive one-page redesign (no build step, no dependencies).

## Design notes

- **Palette** — anchored on the pale logo green (`#BCD2B6`), with cream `#FAF7F0`, deep forest `#3E4A38`, sage `#8FA983` and a soft blush `#E9C9C2` accent.
- **Typography** — editorial serif headlines with italic sage accents.
- **Motion** — gently falling petals in the hero, drifting gradient blobs, a slow service marquee, a growing botanical line drawing, scroll-reveal animations and subtle hover lifts. All motion is disabled when the visitor prefers reduced motion.
- **Content** — based on the current site's structure: Huwelijken, Ikebana (Sōgetsu), Workshops, Abonnementen, Freelance design, Grafstukken, Portfolio, Contact.
